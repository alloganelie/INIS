# INIS — Definition of Done

## Une tâche est Done si

- [ ] le code respecte l'architecture ;
- [ ] les règles de coding sont respectées ;
- [ ] les noms respectent `NAMING.md` ;
- [ ] aucun fichier hors zone n'a été modifié sans autorisation ;
- [ ] les contrats publics sont inchangés ou documentés ;
- [ ] les tests pertinents passent ;
- [ ] aucune erreur silencieuse critique n'a été introduite ;
- [ ] aucune donnée sensible ou secret n'est commité ;
- [ ] les migrations nécessaires sont présentes ;
- [ ] les logs et traces nécessaires existent ;
- [ ] le rapport de livraison est fourni.

## Une phase est Done si

- [ ] toutes les tâches de la phase sont Done ;
- [ ] toutes les branches ont été intégrées ;
- [ ] tests unitaires verts ;
- [ ] tests d'intégration verts ;
- [ ] Docker démarre correctement ;
- [ ] migrations propres ;
- [ ] aucun conflit de contrat connu ;
- [ ] validation fonctionnelle humaine effectuée ;
- [ ] documentation mise à jour ;
- [ ] tag de phase créé.

# Agent Workspace

Zone de coordination des agents logiciels locaux.

- `CURRENT_PHASE.md` : phase active.
- `AGENT_STATUS.md` : état déclaré.
- `AGENT_HANDOFF.md` : protocole de relais.
- `AGENT_WORKSPACE_PROTOCOL.md` : règles worktrees.
- `contracts/CONTRACT_FREEZE.md` : contrats sensibles.
- `tasks/`, `reports/`, `handoffs/` : coordination.
